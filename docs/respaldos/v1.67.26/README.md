# Respaldo de las animaciones de v1.67.26

Copia íntegra, **anterior al ajuste de la hombrera y del movimiento**, del clip equipado, la animación del ítem doblado y el proyecto editable de Blockbench.

- [Fuentes de referencia](https://github.com/Santi-PdR/modelos/tree/e240b7eef101ff47da85900db837f1dd740bd175) (incluyen la mezcla y las correcciones de pose que no se guardan en los clips).
- [JAR verificado de la versión anterior](../../releases/v1.67.26/notas.md), para volver a probar exactamente ese comportamiento sin recompilar.
- [SHA-256](SHA256SUMS.txt) de estas tres copias. El respaldo no se empaqueta en el mod.

Para recuperar las curvas en una edición posterior, importar el proyecto de este directorio o copiar los JSON desde `animations/` al mismo subdirectorio de `src/main/resources/assets/capatest/`. Volver a la mezcla equipada anterior también requiere las fuentes de referencia: no basta con copiar el JSON.
